# Everforest Weather App

A beautiful, single-file weather application featuring the calming Everforest color palette. It provides real-time weather forecasts, interactive themes, and detailed atmospheric conditions—all without needing an API key or a local server.

## Features

- **Zero Setup Required**: Simply double-click the `index.html` file to run it in your browser. No server, Node.js, or local host required.
- **Everforest Theme**: Implements both the dark and light variants of the popular Everforest aesthetic.
- **Dark/Light Mode Toggle**: Instantly switch between themes with a smooth transition.
- **Dynamic Backgrounds**: The background styling dynamically updates slightly based on the current weather condition while maintaining the Everforest vibe.
- **Comprehensive Forecast**: Displays temperature, humidity, wind speed, "feels like" temperature, and precipitation probability.
- **Free API**: Powered by the Open-Meteo API, which does not require an API key or registration.

## Usage

1. Open the `weather-app` folder.
2. Double-click on `index.html` to open it in your default web browser.
3. Type a city name in the search bar and hit Enter (or click the search icon).
4. Use the toggle button in the top right corner to switch between Dark and Light mode.

## Technologies Used

- **HTML5**: For the app structure.
- **CSS3**: For styling, animations, glassmorphism effects, and the Everforest theme palette.
- **JavaScript (Vanilla)**: For fetching API data, handling the UI state, and toggling themes.
- **Open-Meteo API**: For fetching live weather and geocoding data.
- **Google Fonts (Outfit)**: For clean, modern typography.
- **Font Awesome**: For beautiful weather and UI icons.
